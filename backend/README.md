# API

POST `/fcgi-bin/check` с `Content-Type: application/x-www-form-urlencoded`

```text
x=-1&x=0&x=0.5&y=1&r=2
```

Можно передать несколько `x`, но только один `y` и один `r`
Если хотя бы одно значение неверное, весь запрос отклоняется
Максимальный размер тела запроса 8192 байта
Дробные числа принимаются с точкой или запятой, в ответе разделитель всегда точка

| Параметр | Допустимые значения |
| --- | --- |
| `x` | −2, −1.5, −1, −0.5, 0, 0.5, 1, 1.5, 2 |
| `y` | Десятичное число строго между −3 и 3 |
| `r` | 1, 2, 3, 4, 5 |

Ответ

```json
{
  "results": [
    {"x": "-1", "y": "1", "r": "2", "hit": true},
    {"x": "0", "y": "1", "r": "2", "hit": true},
    {"x": "0.5", "y": "1", "r": "2", "hit": false}
  ],
  "currentTime": "2026-11-16T12:00:00Z",
  "executionTimeMs": 0.123456
}
```

Координаты и R приходят строками, чтобы JavaScript не округлял длинные дроби
`currentTime` содержит серверное время в UTC, `executionTimeMs` содержит время чтения, проверки и расчёта всего запроса в миллисекундах

При ошибке вместо `results` приходит `error` с сообщением
Время и длительность есть и в ответах с ошибкой

Статусы ответа

- `200` успешно
- `400` неверные данные
- `405` нужен POST
- `415` неверный Content-Type
- `500` ошибка сервера
